# Theory of Interest

Repository kumpulan materi, slide perkuliahan, catatan/ringkasan, latihan soal, dan pembahasan tugas mata kuliah Theory of Interest (Matematika Keuangan / Teori Bunga).

## Struktur Direktori

Struktur direktori disusun modular per topik/bab materi dengan subdirektori standar:

- **`<Nomor Topik - Nama Topik>/`**
  - `slides/`: Slide perkuliahan.
  - `catatan/`: Ringkasan teori, formula, dan konsep materi.
  - `tugas-dan-latihan/`: Latihan soal, tugas, dan pembahasannya.
- **`Past Problems/`**
  - Arsip soal latihan, ujian (UTS/UAS), dan soal ujian profesi/aktuarial sebelumnya.

---

## Catatan Tambahan (LaTeX & Git)
Repository ini telah dikonfigurasi dengan [`.gitignore`](.gitignore) untuk mengabaikan file cache/temporary LaTeX compiler (`*.aux`, `*.log`, `*.synctex.gz`, `*.fls`, dll.), sehingga hanya file sumber dokumen (`.tex`) dan hasil akhir (`.pdf`) yang dilacak oleh Git.
